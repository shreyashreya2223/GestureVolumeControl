Project Overview

Gesture Volume Control is a real-time computer vision based system that allows users to control system audio levels using hand gestures captured through a webcam. The application integrates MediaPipe hand tracking with a web-based dashboard for real-time visualization and interaction.

Core Functionalities

  • Real-time hand landmark detection
  • Distance-based volume control with smoothing
  • Live webcam feed streamed via Flask
  • Manual gesture calibration (minimum and maximum)
  • Start and stop gesture detection
  • Real-time FPS and system feedback

User Interface

  • Professional dashboard layout
  • Dark and light theme support
  • Interactive volume bar and history graph
  • Responsive layout for different screen sizes

Technology Stack

  • Python, OpenCV, MediaPipe
  • Flask for backend and video streaming
  • HTML, CSS, JavaScript for frontend
  • System audio control using Pycaw (Windows)

Applications

  • Touchless media control
  • Accessibility-focused interaction systems
  • Human–Computer Interaction research
  • Smart environment demonstrations
